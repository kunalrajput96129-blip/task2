📱 Responsive Fluid Grid

Adapts seamlessly from mobile devices to ultrawide desktop monitors using fluid typography `clamp()` and auto-fit CSS Grid.

  • Mobile (320px - 767px): 1-Column stacked view, sticky bottom nav, touch targets >= 48px.
  • Tablet (768px - 1023px): 2-Column fluid grid, collapsed top bar, expandable filters.
  • Desktop (1024px+): 3-Column service cards grid, persistent accessibility toolbar.
